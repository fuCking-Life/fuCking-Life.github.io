无损清理也会引发“边读边忘”死循环，摘要会衰减也会炸空

今天最大的收获是： 无损清理也不是免费的，有损摘要更靠不住。 改写历史前面的任何一条都会打断前缀缓存；当任务工作集大于上下文阈值、模型又不记笔记时，无损清理会把 agent 困在“边读边忘”的死循环里；而把安全约束放进普通对话消息里，不仅多次压缩会“传话衰减”，摘要调用一旦预算耗尽返回空串，约束还会瞬间清零。
