什么才算 agent

今天最大的收获是一个判断标准： 下一步做什么、什么时候停，由模型决定的才是 agent；规则事先就能写死的部分，交给代码。 两道判断题我都答对了，但有两处说法不准：一是以为 ReAct 里有"反思"这一步，二是把"有工具"当成了 agent 的标志。还有一道题没答完。
