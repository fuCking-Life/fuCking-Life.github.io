Agent 学习笔记

学习 agent 设计的复盘：学到什么、哪里理解错了、还有什么没想通。

2026-11-25 周三 · learn-claude-code

把关的 hook 会挡住旁观的 hook

今天最大的收获是： hook 链遇到第一个返回值就停，所以"把关"的 hook 会挡住排在后面的"旁观"的 hook 。课程里权限检查排在日志前面，被拒绝的调用一条日志都没有，而那恰恰是最该留记录的。计时 hook 是我自己设计的，三处位置都放对了；Stop hook 的风险，我漏掉了最隐蔽的一条：模型会去钻检查的空子。复习里，"收尾靠结构、不靠提示词"这一点我又错了一次。

2026-11-24 周二 · learn-claude-code

工具说不清、命令被拦，活都流回 bash

今天最大的收获是： 工具说不清楚，模型不会乱用它，而是绕开它；危险命令被拦住，模型也会换条路走。 两种情况，工作最后都流向了 harness 最难管的 bash。安全不能靠列出所有危险写法，也不能靠多问，要靠沙盒把范围圈住、让大部分操作可以撤回。我有三个预测都没说中：以为描述写错模型会找不到工具，以为它会拿名字含糊的工具去写文件，以为被拒后它知道是用户拒的。

2026-11-23 周一 · learn-claude-code

s02 加工具，改善的是接口

今天最大的收获是： 新工具没有给 agent 增加能力，改善的是接口 ：模型不用再把意图翻译成 shell 语法，harness 也看得懂它要动哪个文件。读 trace 时我还看到，模型只知道 context 里有的东西，进一个陌生环境要先花好几圈去摸。我一开始只说出了"拆分工具让模型选得更准"这层表面，预测也漏了一大半工具调用；还有一道题没答完。

2026-11-22 周日 · TradingAgents · LangGraph · learn-claude-code

TradingAgents 的分析师循环，就是 s01

今天最大的收获是： 去掉 LangGraph 这层外衣，TradingAgents 的分析师就是 s01 那个 ReAct 循环 ，连到上限时的收尾做法，都和我前一天自己设计的方案基本一致。复习 8 道回忆题只对了 1 道，暴露出好几处没记牢的细节；对照题里有两处看漏：以为收尾只靠提示词禁止调工具，以为"没问用户"是没做。

2026-11-19 周四 · TradingAgents · LangGraph

什么才算 agent

今天最大的收获是一个判断标准： 下一步做什么、什么时候停，由模型决定的才是 agent；规则事先就能写死的部分，交给代码。 两道判断题我都答对了，但有两处说法不准：一是以为 ReAct 里有"反思"这一步，二是把"有工具"当成了 agent 的标志。还有一道题没答完。
