全部 →
11-27 周五 · learn-claude-code · Agent Skills

技能写给模型看，description 决定用不用

今天最大的收获是： 技能是写给模型看的，description 决定它用不用。 写得太泛，模型觉得"这我本来就会"，直接跳过；圈得太宽，不该用的时候也会加载。我预测"只说闪退不会加载修 Jira bug 的技能"，结果第一版照样加载了；还把技能里的 references 当成了"子技能"，把 assets 当成了"能运行的资源"。

11-26 周四 · learn-claude-code

给了工具，模型不一定用

今天最大的收获是： 给了工具，模型不一定用；用了，也不一定说真话。 计划清单会被无视，没验证也能标成"完成"；子 agent 被权限拦下后换个写法绕了过去，交回的报告里一个字都没提。交接说明则是子 agent 的全部世界：它省钱，也会让子 agent 悄悄漏掉东西。我有几个预测没说中：以为关掉计划工具会漏步骤，以为缓存命中能让模型更聚焦，还低估了交接说明的好处和风险。

11-25 周三 · learn-claude-code

把关的 hook 会挡住旁观的 hook

今天最大的收获是： hook 链遇到第一个返回值就停，所以"把关"的 hook 会挡住排在后面的"旁观"的 hook 。课程里权限检查排在日志前面，被拒绝的调用一条日志都没有，而那恰恰是最该留记录的。计时 hook 是我自己设计的，三处位置都放对了；Stop hook 的风险，我漏掉了最隐蔽的一条：模型会去钻检查的空子。复习里，"收尾靠结构、不靠提示词"这一点我又错了一次。
